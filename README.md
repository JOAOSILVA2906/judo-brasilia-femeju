# Judô Brasília — FEMEJU

Site estático multipágina criado a partir do layout enviado.

## Páginas
- index.html
- competicoes.html
- ranking.html
- noticias.html
- federacao.html
- documentos.html
- categorias.html
- area-judoca.html
- contato.html

## Observação
O ranking, login e formulários estão funcionais no front-end como demonstração. Para produção, conecte-os a um backend/API e banco de dados, além de substituir os conteúdos e imagens provisórios por materiais oficiais e licenciados.

Abra `index.html` em um servidor local (recomendado) ou hospede a pasta inteira.
